# Security Engineering Projects

A collection of independently developed security tools, automation workflows, and engineering experiments.

These projects focus on applying software development and engineering practices to real-world cybersecurity challenges, including threat detection, incident response, and investigative automation.

## Projects

### 001 | Password Spray Analyzer with AI Summaries

**Technologies:** Python, Docker, REST APIs, Microsoft Entra ID, OpenAI API

A Python-based prototype that analyzes synthetic authentication events to identify potential password spraying activity.

The project incorporates detection logic, AI-generated investigation summaries, and containerized execution.

**Development areas:** Automated testing, CI/CD integration, and expanded telemetry support.
